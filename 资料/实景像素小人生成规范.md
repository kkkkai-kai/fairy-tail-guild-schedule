# 妖尾公会 · 实景像素小人生成规范（v115 定稿）

> 适用：公会实景场景中的 RPG 像素小人（guild-hall-sprite）素材生成与迭代。
> 用户已多轮否决高清赛璐璐、16-bit 插画、萌系 Q 版、AI 厚涂渲染。**最终定稿风格：复古 JRPG 游戏像素 sprite**。

## 一、风格定稿（硬约束）

- **画风**：复古 JRPG（GB/GBA 时代 RPG）行走小人 sprite —— 全身、头身比约 1:2.5~3、方块色块拼接、轮廓硬边、无细腻渐变。
- **分辨率与质感**：成品为真正的低分辨率像素图（高约 64~96px），放大后能看到明确像素格子；禁止平滑抗锯齿、禁止 AI 厚涂质感。
- **发色**：按角色原作发色（纳兹=樱粉、露西=金黄、艾露莎=绯红等），**用平涂色块表达，不做粉紫渐变、不做亮粉高光**。
- **姿态**：直立全身、双脚着地、占满画幅约 80% 高度；透明背景（png），无阴影地板或场景道具。
- **识别度**：必须一眼认出角色（发型/发色/标志性服装配色/武器或道具）。

## 二、通用提示词模板（图生图 / 文生图均可）

```
复古JRPG像素风游戏小人，全身站立像素sprite，透明背景，头身比约1:2.5，
平涂色块、硬边缘、无抗锯齿，{动作}姿态，
角色：{发型描述}，{发色}平涂，{眼睛颜色}，{服装描述}，
{标志性配饰/道具}，整体占画幅高度约80%，
严格低分辨率像素质感，无渐变、无柔光、无厚涂、无萌系Q版大头、无亮粉高光。
```

按角色替换 `{...}` 字段。文生图（image_gen）直接使用；图生图（image_edit）时把原图作为参考并写明"保持像素 sprite 构图与配色逻辑，仅替换角色特征"。

## 三、负面词（写进 prompt 的排除项）

不要：高清赛璐璐动画渲染、厚涂插画、水彩、3D、Q版大头、萌系圆脸、柔光渐变、发光高光、复杂背景、地面阴影、写实皮肤、AI 油画质感、过度精致的发丝。

## 四、后处理（必做，保证真像素）

生成结果默认是高清图，必须降采样成真像素 sprite：

1. 用 PIL 最近邻（NEAREST）缩到目标高度（默认 96px，保持宽高比）；
2. 需要时再用 NEAREST 放大回 2~3 倍作为展示/切图原稿（对象显示尺寸由 CSS 控制）；
3. 若角色边缘有半透明杂点，先做透明度阈值处理再缩放。

```python
from PIL import Image
img = Image.open(src).convert("RGBA")
# 抠掉杂点：alpha<20 的像素置透明
img = img.point(lambda a: 0 if a < 20 else a)
w, h = img.size
target_h = 96
nw = max(1, round(w * target_h / h))
pix = img.resize((nw, target_h), Image.NEAREST)
pix.save(dst)
```

## 五、命名与接入规则

- 存放到 `素材\人物\{id-中文名}\像素小人\guild-sprite-{id}-{state}-v{n}.png`（state 见 guild-assets.js `hallStates`：daily / walk-a / walk-b / rest / return / celebration / eating / thinking）。
- 接入前运行 `node 工具\更新素材索引.cjs` 更新 `素材\目录索引.json` 与 `代码\guild-assets.js`。
- 生成后必须在浏览器实景中实测显示效果，不能只看图片本身。
