## 默认规则

- 关注：应激颗粒、应激与 Zn²⁺、两者交叉、犬 CAR-T。RNA 自噬暂停，不删除已有 PDF。
- 点击更新才检索。Europe PMC 查询近 30 天首次发表记录，优先近 7 天；每个主题最多 40 条。每批选 3–5 条（不足不凑），其余在“全部候选”。重复 DOI/PMID/题名作者年份不重复登记。当前只有一个检索源，未覆盖所有未被索引的新论文。
- 题名/摘要规则初筛，不冒称已阅读全文；交叉相关性、犬模型、总锌/游离锌/探针信号要阅读验证。不把 JIF 当文章质量。
- JIF 必须附指标年度和核验来源，初始指标库为空，未知“待核验”、预印本“不适用”。手工核验录入不是自动获取 JCR 订阅数据。
- NPC 沿用现有公会访客（兼容同人 NPC，不冒称原著正式成员），当天稳定选择一位；有新批次才出现在情报角，查阅呈递后转为大厅访客。无正式任务、无奖励结算。
- 收藏不自动登记任务。收藏后默认尝试下载合法公开 PDF；失败/需授权仍保留文献。优先使用 PMC 当前公开数据服务：核对题名/DOI、许可、版本与 MD5，并保存 SHA-256。其他来源只验证 PDF 格式，题名/DOI 身份仍需核对，不声称自动读懂全文。无公开 PDF 不绕过付费墙。
- Windows 文件名为首次收藏北京时间日期 + 原文完整题名；非法字符清理，过长题名截短（原题保留记录），预印本加后缀，冲突加短标识。不覆盖不同文件。

## 其他 AI 复用

先读取本文件和 `_管理/文献记录.json`，以 DOI/PMID 去重，不另建独立数据库。需有该电脑的本地文件/联网权限。
在项目目录用 Node 执行 `工具/公会文献服务.cjs`：

```
node 工具/公会文献服务.cjs search
node 工具/公会文献服务.cjs status
node 工具/公会文献服务.cjs import 已核验文献.json
node 工具/公会文献服务.cjs collect "doi:10.xxxx/yyyy"
node 工具/公会文献服务.cjs download "doi:10.xxxx/yyyy"
node 工具/公会文献服务.cjs export-ris
```

服务运行时优先通过页面导入；其他 AI 也可以使用 CLI。写入队列配合本地进程锁，避免服务和 CLI 同时覆盖记录；锁等待超过 20 秒会提示稍后重试。不得绕过工具直接整份覆盖共享 JSON。
导入 JSON 数组每次最多 200 篇，必需 `title` 和真实 HTTPS `sourceUrl`；可带 `doi/pmid/authors/journal/issn/year/publishedAt/abstract/preprint`。外部 AI 导入标“待核验”，不接受任意 PDF 链接，不能凭空写 JIF 或论文结论。
RIS 可导出给 EndNote，本轮不自动修改 EndNote 库。暂无无人值守定时检索。

## 单篇卷宗呈递（v146）

每篇记录保存自己的 courier 与 dispatch。点击来访者只打开对应论文，关闭或切换页面不会接收整批文献。“收下卷宗”只收藏当前一篇；“暂存线索”保留候选，不计任务、经验或奖励。旧批次的自动 presentedAt 不作为用户已接收的证据。

情报角最多五位文献来访者，其他卷宗排队；处理后空位可补入下一位。只有收下卷宗的来访者，在当天有空位的公会房间做客；暂存或略过后离开站位，可恢复待呈递。复用八位已有原创 NPC 形象，不宣称它们是原作角色；NPC 可以以后再次送来另一篇论文，但同场不重复出现同一形象。76 条已有记录已保留并建立对应关系。

页面采用来访卷宗目录与单篇阅读区；期刊指标、导入、RIS 和下载设置保留在次级资料管理中。尚未核验的 JIF 不伪造数值。

## 安全边界

服务不执行用户传入的命令、不提供任意本地文件读写接口。PDF 核验只调用固定本地 Python 检查脚本和已有 pypdf，不安装依赖；仅解析首页，20 秒超时，解析不可用则待核验。写接口要求本地页面来源与随机运行期令牌；公开概况仅含人数和人物对应关系，不返回论文笔记或文件路径。PDF 只尝试源站返回的公开链接，拒绝私有地址并限制大小、超时与跳转次数。资料文件不要推送公开仓库。

## 保存回执与整理（v147）

PDF 文件存在、首页题名/DOI匹配、发表版本是三个独立结果。扫描件不强行确认；参考文献中的 DOI 不作为匹配依据。重新核验同时检查 SHA-256 是否变化，文件缺失在页面即时提示。查看 PDF 只读取已收藏记录对应目录内的 PDF；不提供用户任意路径读取。

研读角按待获取全文、待研读、研读中、已整理分组，保存研究问题、支持证据、局限、下一步札记。重复 DOI 补充来源及主题标签，不覆盖笔记、收藏日期、人物或 PDF。新发表与近期补收分别标识，无法确认的旧记录按补收展示。出版更新为用户主动查询 Crossref 记录，未发现更新不代表保证没有撤稿或更正，暂无自动监测。

今日动态物件归告示厅；情报角使用透明研究密函 SVG，不使用白色底板。文献来访者缩小到 40×44px，五个独立安全站位。资料管理和期刊指标为次级入口。

接口依据：[Europe PMC 检索接口](https://europepmc.org/RestfulWebService)、[PMC 当前公开数据服务](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/)。不使用已经停用的旧 PMC OA API。
