# 文件与素材清理

用户2026-10-04已授权本系统的日常代码备份轮换和已执行提示词清理；范围仅限本项目。未知素材仍先审计，不把调用技能扩展为删除真实任务数据或其他项目的授权。每轮执行前先在聊天输出实施提示词，不创建提示词文件。

## 范围与判定

- 限已核对的项目源目录、D盘镜像以及本轮自身临时文件。不得递归删除项目根、Git目录、浏览器配置、密钥目录或其他聊天附件。
- 每个删除目标先解析绝对路径，确认在指定目录内。用同一种PowerShell执行检查与删除，使用LiteralPath，拒绝链接/重解析点，不通过cmd或字符串拼接执行路径。
- 旧版本号、年龄、文件名含backup或静态搜索未命中都不能单独作为删除依据。检查当前HTML加载链、动态注册/拼接路径、回退、SW、数据保存的素材选择以及保留备份的用途。
- 已完成记录、真实任务JSON、云端恢复前后快照、唯一原始精灵表、未完成迁移工具、凭据和无法确认的文件默认保留。不清localStorage、云数据或已有用户导出。

## 可处理类别

1. 本轮及确认属于旧测试的截图、隔离页面、临时脚本、合成测试结果：无运行引用后可删除。
2. 重复原图：SHA-256完全相同且另有可访问原始文件、有效网页轻量版，当前及保留备份不用该副本，才删除重复副本；记录原图恢复路径。没有原图副本时不要因已有WebP就删唯一源图。
3. 代码备份：源目录、镜像目录各最多保留最近5代可用回退点；同一版分散的快照按一代计算，旧嵌套“版本备份”也计入，不能只清理根目录。新快照先完整复制实际入口、核心脚本、活跃CSS及缓存文件，验证可恢复后再删除超限旧代。不压缩、不新建ZIP归档；经本次授权可删除旧清理归档。真实任务JSON、云历史恢复快照不归入代码5代规则，除非用户明确要求删除历史存档。
4. 已执行提示词：执行与验收完成后可直接删除项目内对应的提示词文件，不再归档，也不生成新的提示词报告。未执行方案、AGENTS.md、技能规则、接入说明及必要素材用途记录不能只因是Markdown就删除；混有仍需保留的维护信息先迁出相关内容。
5. 不再使用的程序/素材：需要检查当前引用、动态路径、回退、旧存档选图和保留5代备份。确认废弃或重复后才删除；用途不明、独有来源图或无法确认历史引用的图片可移到“待人工确认素材”目录，并记录原路径、判定和恢复方式，供用户自行决定。疑似仍有运行用途的保持原位，不能把“静态搜索没命中”当成无用证据。静态站点删除仅处理明确发布文件，不把本地清理扩展成后端清理。

## 执行与交付

- 删除前形成精确清单、分类理由、字节数及恢复方式，向用户简短说明主要类别，不要求为已明确授权的普通清理再次逐项确认；身份/用途仍不明的目标排除。
- 核算净减少量（删除字节减新增备份/素材字节），按C盘/D盘分别统计，不重复计算Git对象。移动到待确认目录不算释放存储。
- 删除后再查实际引用、JS语法、两HTML一致、代表场景图片加载；按授权核验源与D盘相关文件一致。保留小型清理清单，不把私有快照内容公开。
- 说明永久删除、Git或保留备份可恢复分别适用于哪些文件。不得声称全部可恢复；不再用压缩包作恢复承诺。
- v107起代码备份在“备份/代码”，云历史在“备份/云端历史”；后续轮换读取这些目录及遗留根目录，按实际备份时间排序，不能按v89/v107字符串字典序排序。素材归档以“素材/目录索引.json”追溯旧路径，归类不等于净释放存储。
- 旧“代码备份”可能混有真实文献记录等JSON，删除整目录前必须逐文件检查（包括隐藏文件）。真实记录、用途未定资料先转到独立保留目录并SHA校验，不能用文件夹名保证内容全是代码。反向补齐局部快照必须标明重组来源，不冒称原始整站历史；缺省共用现有素材，恢复程序后更新缓存版本且不回写个人存档。完整回退集要做隔离启动验收，不只统计文件数。轮换新增副本可能使某盘增大，分别报告净空间，不把删除字节总量当实际释放量。
