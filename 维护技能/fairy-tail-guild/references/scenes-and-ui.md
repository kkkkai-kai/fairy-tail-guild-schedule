# 实景、互动与UI

## 空间和功能

- 大厅中心，其他房间独立按钮直接可见，不恢复统一下拉选房。按委托/资料/休整关系排列，图标/名称/人数清晰，不压缩实景。
- 基线mainHall / missionBoard / intelCorner / archiveRoom / researchRoom / guildTavern / happyNook；名称按当前UI，不冒称新增房间是原著官方。
- 内在联系要有归队、委托、资料、休整逻辑，切换有简短过渡词。不要底部冗余跳转、虚线连线、轮次或几分钟刷新倒计时。
- 普通协助者完成任务后归队，不接取就庆祝。情报角每日派送者是明确入口例外，完成后转入其他场景。
- 今日动态/见闻融入情报角，发光卷轴/信封/记录本点击展示，释放主区；不铺冗余按钮，不把哈比小窝混到情报角。
- 哈比常驻小窝，其他四只超越者每天稳定随机0或1位，或按完成其委托入场；具体优先级核对实现。必须妖尾角色，不用普通猫替代。
- 所有人可点击互动。哈比保留专属投喂、玩耍、心愿和现有库存入口，不为统一界面删功能。互动可跳过，不强迫或失败扣罚。

## 活动范围与对白

- 真透明2D像素全身小人，无圆框、矩形底板或白底；任务头像仍是圆框。
- 脚底锚点按实际显示宽高/舞台尺寸/边距限制完整人物。每房间地面站位单独配置，避开墙柜和家具。
- 图像载入、舞台尺寸变化、场景切换和移动结束都校验边界，不能只限制坐标点或沿用错误初始高度。
- 只运行当前场景一个调度器，换场停止旧动画/计时器，后台与减少动态不强制播放。停留后移动，不抖动。
- 定时分房可后台执行，所有人可回大厅；任务身份不能随重新分房改变。
- 悬停与键盘聚焦有可读短对白，点击互动；提示边缘避让。相遇用实际移动后距离，按人物对/日期/场景去重，不跨场景对话。
- 纯见闻/小提醒完成不自动发正式任务奖励。

### 人物日常真实感与素材覆盖

- 完成记录只决定普通成员入场资格，不把所有归队者永久设为欢呼。短暂归队致意后恢复日常姿势；仅实际参加庆典的人物，在指定欢呼/举杯环节使用庆祝动作，结束立即恢复。围观者、其他房间人物不跟着庆祝。人物活动与任务完成状态分别表达，不能改动任务账本来切动作。
- “人物形象够不够”分开审计角色覆盖、独立全身动作、头像、状态表、实际接入和加载。多个状态键指向同一文件只算一个动作；半身头像表不能冒充全身像素小人；文件存在不证明身份或风格正确，旧verified标志也不是新的视觉验收。
- 为真实感优先补同一角色的日常动作，而不是无限增加角色和庆祝图。可选优先级：主角团待机、行走、休息与代表性活动，再补常出现成员；站立、坐姿、读书、吃东西等必须与原作角色特征及场景家具相容，不能为了随机把每个人都套上同一行为。这些是建议，不授权自动生成全部素材。
- 动作、对白和悬停描述一致，只描述图像/动画确实表达的行为；不把静态站立宣称为读书或工作。沿用唯一当前场景调度器，活动按停留时段温和变化，不每秒随机、持续跳跃或刷新换人。移动目的与场景安全站位对应，坐姿需实际座位锚点。
- 使用已验证正确素材优先；风格不统一时先做代表样张与页面缩小验证，禁止一次重做全部。新素材仍按分类目录接入，按需加载，不预载全员全部动作。
- 基于既有图片统一风格与后续创新时，读[人物画风延续规则](character-style.md)；保留固定风格基准和每个角色的身份参考，禁止生成结果逐代漂移。

## 素材、天气、庆典

### 大厅散场与召回（2026-10-06约定）

- 日常大厅每日稳定选择普通或安静休整主题（北京时间日期种子），同日刷新和跨端不换主题；主题各按四时选图，复用已有轻量图。宴席、余兴、闭馆仅限事件，不把明显宴会残留当普通日常。事件优先，召回恢复当天主题；不改变任务、奖励、人物入场条件或为主题增加计时器。

- 散场／召回融入现有大厅场景按钮，独立点击命中区不触发换场；不新增说明栏、按钮行或页面高度。保留键盘可用与禁用状态提示。
- 每天首次主动散场随机选一种方案并保存，当天刷新、召回不重复抽取。召回恢复原有入场资格和房间分配，不发奖励、不改任务或人物身份。散场包括哈比小窝当天出现的超越者；散场后所有房间不再出现这些成员，召回后小窝恢复。
- 欢快／安静告别允许不同节奏与对白，但静态小人不可冒称已具备击掌、吃饭等独立动作。雨天方案仅在有效雨天记录下进入候选池。
- 散场按串行队列逐个离开，前一位到达出口并淡出后下一位再动；正常每位约3–4秒、间隔约0.7秒。不能用短延迟叠加全员淡出冒充依次走；保持脚底边界和原有定位变换，减少动态模式保留顺序但缩短移动。
- 散场期间普通刷新不重建离场节点；序列结束恢复渲染。待呈递文献NPC优先保留情报角五个站位，不能因容量筛选丢失人物。本地来信按最新一批未读文献统计，首次打开与北京时间10/14/18时段去重提示，全读完停止。文件更新不等于运行中的本地服务已重启。
- 状态背景按宴席 supper、余兴 afterparty、收整 quiet、闭馆 closed × 北京时间 dawn/day/sunset/night 明确映射；已有正确时段图复用，仅补缺项。窗口天空和入射光必须符合时段，不用整体滤镜把夜图冒充日图；缺图回退当前时段的正常大厅，不能报告为素材已补齐。
- 改图保持同一参考的建筑、镜头、家具和像素密度，人物继续独立渲染。按需加载当前状态／时段轻量图，不首屏预载全部16张。召回恢复当前时段正常大厅和闵行天气。沿用单一时间检查，不增加第二套刷新调度器。
- 散场状态是展示层，程序与素材同步不等于跨端个人存档迁移；是否跨端共享散场记录需另核对同步白名单，不能默认改云存档。

- 联网核验原著角色发色、服装、体型、配件与建筑要素；生成用参考图，不让生成器凭名字猜。不能确认的新增空间标兼容同人设计，不保证与原著一模一样。
- 优先复用正确素材，缺失才生成；编辑既有图做四时/天气，固定结构、家具、镜头与配色。
- 北京时间清晨/白昼/黄昏/夜晚；现实天气参照上海市闵行区，有来源和更新时间。失败提示不可用/上次记录，不默认晴、不随机雨雪，不把实况说成原著玛格诺利亚天气。
- 背景注册表按场景/时段映射，检查实际图片身份、尺寸、解码和浏览器src，不仅文件存在。
- 自然比例完整展示，不强制所有房间3:4；新图解码后替换旧图，短过渡、不灰白遮罩，快速点击只应用最新请求。
- A/S完成可有多种盛大且原著兼容的图像/小人庆典；至少4张是历史内容目标，先审计不重复生成。庆典替换背景，不叠正常图；一次入口有动作/对白/有限动画，不重复奖励。
- 魔法阵不是必需，尤其实景不自动重新加。仅本次明确需要且不遮人/不降性能才使用。

## 大模块和排版

- 每个大模块有肉眼可见专属边框、区别角饰/主题，共同色板；不能以三个共享框代替全部，不遮文字或吃掉实景。厚度与角饰按主次分层，不全部统一粗框；子卡用细边，人物装饰主题不改变任务协助者。
- 新角色边框以已接入的纳兹/露西边框为实际图像参考，匹配手绘线稿、雕刻材质、角饰细节与完成度，不只换色加符号。采用不对称但平衡的主角饰、不同形态次角饰、两处简洁收口；禁止四角复制、镜像同饰和整圈堆满主题符号。不同角色逐款生成，不合成多框小格草稿替代正式素材；检查单款及页面缩小效果再接入。原作只核对角色主题，UI是兼容同人设计，不冒称原著官方边框。
- 同类框线按下节“边框光学一致性”验收，装饰主题不能代替厚度标准。
- v104为19个大模块、16新边框+3旧专属框，样式guild-ui-v104.css；后续重新审计数量/入口，不硬编码19。
- 色板胡桃木、旧铜、羊皮纸、少量深红；等级状态色保留语义，不堆霓虹。保留原人物剪影，不用实体底板掩盖。
- 场景专属图标小而清晰，按钮名称完整/对比充分；字体少量统一层级，不全都夸大加粗。
- 任务三列固定头像+minmax(0,1fr)正文+操作；长标题自然换行，按钮整组合理换行，不逐字竖排或大留白。
- 综合档案展开可滚动，羁绊等子区不自动全开；主等级清晰，称谓不变。
- 操作保留页面、左栏、列表滚动和输入焦点，不重建整个侧栏或导航页顶。
- 现在仍需手机适配，快速登记顶部，自然整页滚动、足够触控区、无横向溢出。

### 边框光学一致性

- 先给模块确定语义类别与层级：同类大模块共用框线标准，不因角色名字临时变厚；主卡、常规卡、辅助卡和子卡可以有明确层级差异。角色特色主要由角饰、纹样和少量强调色体现，主角饰较大不等于整圈框线都加厚。
- 分别记录布局预留、可见直线框轨、角饰外延和内边距。相同border-width或border-image-width不保证可见框轨一样厚；须检查源图Alpha留白、框轨像素厚度、切片比例、缩放和最终CSS层叠。同类图片使用18%与32%等不同切片时尤其要核对，不盲目统一切片导致角饰被截断。
- 以同尺寸页面样张校准上/下/左/右直线段，避开角饰。可用Alpha中段采样估计框轨厚度，再用浏览器实际截图验收；单边估计不是整框已验收。同类框轨允许小幅光学补偿，但目标值与容差须明确，不能把不同图片套同一22px后就报告“厚度统一”。
- 如果校准框轨会使角饰过小，分离共同框轨与独立透明角饰层；不为装饰添加影响按钮点击或占用实景空间的层。保留角色不对称设计，不简单把所有专属框换成通用框。
- 装饰透明处不得露出旧矩形边线、实体底板或矩形阴影。核对background-clip、底板形状、旧border/outline/box-shadow及伪元素；border-radius本身不会把border-image裁成圆角。桌面窄宽、手机、弹窗与展开状态都检查角落，不用与背景同色的遮板掩盖。
