# 任务、人物与数据

## 现实与世界观

用户通常只输入现实目标，不要求世界观词。保留原文，识别性质/复杂度，再写独立公会注释：
- 整理IFA图：原名保留，分类实验与数据，展示研读/研究协助，不虚构结果。
- 阅读论文笔记：资料研读，附档案整理说明。
- 联系老师确认仪器：沟通预约，不因老师/仪器判S级。
- 多批次分析报告：结合步骤、验收物、验证要求判断，不凭“提交”单字判高级。
- 登记抗体/耗材库存：真实物资管理，不连接采购支付，也不提供无关实验操作流程。

类型、分类、等级、角色身份、公会注释独立。用户明确选择优先。

## 登记与时间

- 沿用daily / once / project结构。顶部快速登记和完整表单复用一个创建入口。
- 预测类型、委托等级、酬劳范围、日期证据与待确认项须可见；信息不足说明不足，不继承上一条S级选择冒充预测。手工字段优先，改输入使旧自动预览失效。
- 保存后明确进入哪个区域；排查创建→保存→云合并→筛选，不追加重复任务掩盖消失。
- 最新明确要求取消计划时间：新识别时间用于due/dueTime，不新写plannedAt；旧字段兼容保留。startedAt只由实际启程写入；reminder仍独立可选。
- “明天14点处理”按最新单一时间模型提出截止候选，不重新加计划入口；“三天内完成”识别相对截止；“未来三天看看”提示范围歧义。
- 时长/次数/编号不是日期，否定、待定、多个冲突日期不能静默写入。下午/晚上未指定小时不发明14:00或20:00。
- 基准Asia/Shanghai，不以UTC截断今天；已过去的本周日期不悄悄挪到下周。
- 相对自然月按日历月计算，半年为6个月，目标月没有同一日期时夹到该月最后一天；不能用30天/月或180天/半年近似。只影响新识别，旧任务不重新改期。
- 中文复杂度从行动、步骤和交付理解，不靠几个词判S级；专业实验术语只用于任务分类，不是实验流程生成任务。

## 流转与远征

- 项目隔离回归位于工具/测试，修改闭环逻辑后运行适用测试；公会闭环测试阻断公网，文献接口测试使用临时资料目录。测试通过只证明README列出的覆盖范围，不证明生产存档、云端权限或真实双端同步。

- v163今日出征：计算预算和渲染共用候选规则；当天移出用独立排除清单，不能只删置顶后又由逾期评分选回。重新加入解除排除；只改变当天聚焦偏好，不改任务状态、日期、奖励或人物。
- 今日出征候选还必须共用实际执行阻塞规则：暂停、明确阻塞、未完成或不存在的前置任务均不得算可执行预算。恢复暂停不等于解除前置；前置真实完成后自然恢复候选，不为恢复重发奖励。
- 复盘文字成果按北京时间完成日筛选，不能直接截UTC时间前十位；无效日期不入统计。等待摘要注明是当前全部等待而非周期内新增，包含前置阻塞；暂停优先明确标为暂停，不以等待对象掩盖状态。
- 复盘主统计同样使用北京时间边界；legacyCounted日常委托已由日程checked计入，不在单次记录再加一次。最终远征按一项、酬劳按原阶段结算读取；只改展示统计，不回算历史账本。
- 周报与趋势共用复盘统计，不能把完整ISO完成时间拼接为日期导致漏算；本周摘要范围从周一至今日结束，不把结束值误设为周一起点。单项“改派至明日”以点击时北京时间当天做日历加一天，不能把本地午夜转ISO后少算一天；按稳定ID操作最新任务，保留原时刻和奖励。
- 取消/撤回确认后重新读取稳定ID并核对批准时状态，确认期间已接取、启程、完成或改名改期时停止操作，不删除新完成记录，也不写入旧对象。等值对象替换应可正常执行；隔离并发测试不冒称真实双端验证。

- v162增量：查找与成果入口复用登记区域；暂停用pausedAt独立记录，不扣罚、不改截止，恢复后仍须解除其他前置/阻塞条件。成果位置只保存文本，不上传附件。下一步只填登记草稿，已有非空草稿不能覆盖，不能继承截止。
- 单次周期委托仅在用户主动设置recurrence后生成下一次，fixed为固定日期间隔、after为完成后间隔；历史保留，nextOccurrenceId防重复，不自动接取。长期远征暂不支持自动复制周期。
- 完成标准、预计投入和等待对象独立字段，编辑取消不写回任务；保存前的恢复点必须记录修改之前数据。

- 未接取单次委托在告示相关视图；接取后才进主要单次委托区。不把待处理委托当所有新任务垃圾桶。
- 七日列表有截止、逾期、未设截止分组按最新实现/要求核对，不能让无截止任务从所有入口消失。
- 主区每任务一次；摘要引用不复制记录。
- 头像+正文+右侧按钮，折叠不藏必要完成/启程入口。新建/删除阶段、备注、阶段完成按钮不能因排版修复丢失。
- 阶段编辑草稿保存在本机会话，不自动上传；重绘保留输入和焦点。同步改名时展示本机草稿与最新名称并拒绝旧值覆盖，提供主动采用最新名称入口；成功保存更新比较基线，不能把下一次正常编辑误判为同步冲突。已完成或取消的阶段仍按既有保护处理。
- 远征绑定主协助者，各阶段同人物不同状态/头像；优先避免同图重复，保存后稳定，不要求不同人物。
- 阶段全部完成后明确最终确认/归队；整个远征按一项正式委托统计，阶段流水保留，不重复发总奖励。
- 完成后剧情/反馈，主列表隐藏但归档保留。完成S级在告示厅实景物件悬停陈列，不回到左侧巨大常驻卡。
- 历史“阶段已完成不可以撤销”有歧义：核实最新要求/可用接口，不把故障反馈当永久禁止，也不因美化删撤销能力。允许撤销则精确反向账本。

## 身份与随机

- 最新偏好全部可分配人物都有非零概率，不是类别硬筛成小池。类别适配、负载与近期重复只调整权重，不能把其他可用角色概率归零。
- 候选来自注册表允许指派且素材有效角色；正式/历史/盟友/访客身份保持准确。visitorId、纯访客与身份不明NPC不自动混入assigneeId。
- 初次创建按稳定种子加权抽取并保存assigneeId，刷新、标题编辑、接取、启程、完成、云同步不换人。
- 默认不加手动娱乐重抽入口，用户后来明确希望自动随机。错误身份纠正仍需证据，不随机重分历史。
- 任务/反馈/归档/实景都走唯一人物解析。旧别名显式兼容，无法确认保留待查。
- 视觉只在同角色素材内变化，任务保存选择优先。加载失败依次尝试同角色备选，不首错永久显示“协”，也不用另一人物替代。
- 圆形任务头像和透明全身小人分开组件，不能让全身图越出圆框。

## 账本、成长、内容库

- 自动恢复与外部JSON导入都要在覆盖前保存恢复点，捕获五个业务key和业务内存。中途写入失败须还原；还原本身失败时明确提示停止登记并使用恢复点。单次写入异常通过不证明断电原子性或持续存储故障已解决。
- 兑换确认后重新读取余额、月度预算与兑换比例，不能沿用弹窗打开前的校验；变化则停止并要求重新确认，不重算历史兑换记录。
- 批量改期/暂停确认后按已批准ID重新读取当前任务；名称、截止、暂停或结束状态变化及任务移除时整批停止，请用户重新确认，不部分执行或覆盖新值。对象替换但相关内容未变可正常执行；单项暂停/恢复也不得写入旧对象。

### 文献记录验收补充（2026-10-08）

- 2026-10-09用户定义“略过此篇”为不需要此篇：主动确认后移出情报/研读列表，删除独立PDF、清空笔记/札记/摘要和下载资料，保留最小拒收去重标记，不能自动重新收藏。下载进行中拒绝清理以免重新落盘；PDF仅限文献根目录内普通文件，检查真实路径和其他文献共用引用，共用/越界文件不删除。不批量追删旧略过记录，不扫文件夹推测附件归属；真实删除由用户明确选择单篇触发。

- DOI、PMID规范化与保守题名/作者/年份匹配共用于检索和外部导入；两篇有不同DOI时不因同题名合并。既有重复历史不自动删除，版本关系与重复身份分开。
- 无DOI/PMID时，明确预印本与正式版分别保存，新题名回退ID包含版本；检索、预览、导入采用一致规则，旧ID与笔记不批量迁移。同DOI/PMID仍优先身份匹配，不能把版本关联当自动合并依据。
- 一篇待呈递文献对应一个独立paperId访客；最新五篇的NPC冲突需要稳定补选。领取、研读、PDF保存与任务奖励独立；重复领取不刷新归队时间或重复启动下载。
- 最新五篇待领取和今日已领取访客优先占场景名额；旧批次不能用相同NPC挤掉刚领取人物。来信保留记录，展示容量不足不删除旧文献；无效领取日期不得使整个摘要报错。
- PDF存在不证明正确。核验首页完整DOI而非子串、题名、文件SHA；文件元信息改变则旧匹配降级。完整题名保留记录，文件名在系统限制内尽量完整；不为了命名美观重命名旧PDF。
- 出版更新来源DOI不匹配不能写回；没有关联不证明无撤稿/更正。临时文件、模拟API、实际DOM和真实出版网络验收分别记录，不能混称。
- 本地文献窗口打开时可温和检查已收藏且有DOI的记录：成功结果7天有效，自动失败/中断尝试至少间隔1天；每次最多3篇依次检查，同进程并发开页合并一批。用户可关闭自动检查，单篇主动核对保留；失败不覆盖旧publicationCheck，不改题名/笔记/PDF。自动检查不重绘编辑表单，结果在下次正常刷新/打开查看。服务必须实际重启后才能启用，不能只同步文件就声称运行已更新。

- 完成按任务/阶段稳定ID幂等，连点、重绘、同步重放不再结算。庆典、剧情不二次发任务奖励。
- 单次历史撤销读取当前稳定ID记录，完成时间或结算金额变化时重新确认；恢复done=false和active状态，不能残留completed阻断再次提交。重复撤销不得重复扣除；历史弹窗关闭焦点恢复preventScroll。
- 接取同启程、完成一样，点击时按稳定ID重新获取当前任务对象；委托板与左栏接取按钮也保护按下到click之间不被重绘移除。完成鼓励头像立即按需加载同角色已有头像，不等待离屏观察器或大型动作状态表。
- 当前100级体系称谓/EXP曲线、S—F标签/酬劳从现有代码读取，不擅自重定级或合并旧双轨账。
- J、等级EXP、魔法EXP、人物成长、哈比伙伴EXP、现实兑换预算独立；早期100J=¥1、每月¥300是需核对的既有约定，不覆盖后来的设置。
- 礼物来自可用库存、排除已装备，确认扣一件并记录一次；养成数值不冒充原著战力。
- 礼物偏好可影响正向增益和对白，但不喜欢的礼物不扣羁绊；旧负增长历史不自动回算。
- 2000条名人名言、角色鼓励/故事扩充是单独内容任务，不每次修复都生成。核验出处，原创对白不标原著台词，不能用组合计数冒充已核验引用。
